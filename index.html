Type or paste a whole quiz. Number each question, put choices on lines starting with a. b., and mark correct choices with *. Changes sync to the form as you type.

Text format 
Multiple choice
1. Which system records day-to-day
   transactions such as order entry?
a. Decision support system
*b. Transaction processing system
c. Executive information system
Multiple answer  (two or more *)
2. Which are enterprise systems?
*a. ERP
*b. CRM
c. A personal to-do list app
*d. SCM
True / False
3. A data warehouse is optimized for
   analysis, not for daily transactions.
Answer: True
Essay  (no choices, no answer)
4. Explain one way IT can create a
   competitive advantage.
Sample: Names a strategy and a company example.
Matching
5. Match each security goal to its meaning.
a. Confidentiality = Only authorized eyes
b. Integrity = Data is accurate and unaltered
c. Availability = Systems are up when needed
Fill in the blank
6. SQL stands for Structured ____ Language.
Answer: Query; query
Fill in multiple blanks
7. A [pk] identifies each row; a [fk]
   links one table to another.
pk: primary key
fk: foreign key
Numeric
8. A system costs 40,000 and saves 50,000.
   What is its ROI in percent?
Answer: 25
Tolerance: 0.5

Force a type with a tag after the number: [MC] [MA] [TF] [ESS] [MAT] [FIB] [FMB] [NUM]. Formatting: **bold** _italic_ x^2^ H~2~O $\frac{a}{b}$. Start a line with \ to keep it as text, and lines starting with # are comments.
